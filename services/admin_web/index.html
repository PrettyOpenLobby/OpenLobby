                  Discord bots
                  
        
                  Every game's bot in one place. Paste a bot token and Save: Discord fills in the
          app id and public key, and the bot's service restarts on it within about a minute. A bot with
          nothing saved here keeps its .env values. Tokens are stored sealed with
          POL_BOT_KEY and never shown again.
                  
        
                  POL_BOT_KEY is not set. Tokens cannot be
          stored until it is in .env for the admin and bot services (any long random string).
          Page addresses can still be saved.
                  
        
                  Setting up a new bot: create an application in the Discord developer portal,
          copy its bot token here, Save, then use Invite to add it to a server and
          Set endpoint once the bot shows as running. In the server, run its
          /<name>board command in the channel it should post in. Each card's checklist
          says what is still to do; Check asks Discord again.
